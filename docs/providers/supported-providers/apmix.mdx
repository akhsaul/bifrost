---
title: "Apmix"
description: "Configure Apmix through its OpenAI-compatible API"
---

Apmix exposes an OpenAI-compatible API at `https://api.apmix.ai/v1`. Bifrost uses `/chat/completions` and `/models`.

```json
{
  "providers": {
    "apmix": {
      "keys": [{ "name": "apmix", "value": "env.APMIX_API_KEY" }]
    }
  }
}
```

Requests use Bearer authentication. Chat completions, streaming, model listing, and Responses-to-Chat fallback are supported.
