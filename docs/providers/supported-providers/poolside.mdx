---
title: "Poolside"
description: "Configure Poolside through its OpenAI-compatible API"
---

Poolside exposes an OpenAI-compatible inference API. The default base URL is `https://inference.poolside.ai/v1`; Bifrost uses `/chat/completions` for chat requests and `/models` for model discovery.

```json
{
  "providers": {
    "poolside": {
      "keys": [{ "name": "poolside", "value": "env.POOLSIDE_API_KEY" }]
    }
  }
}
```

Requests use `Authorization: Bearer <api-key>`. Chat completions, SSE streaming, model listing, and Responses-to-Chat fallback are supported. Operations not exposed by Poolside's OpenAI-compatible endpoint return an explicit unsupported-operation error.
