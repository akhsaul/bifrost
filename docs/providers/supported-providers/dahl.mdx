---
title: "Dahl"
description: "Configure Dahl through its OpenAI-compatible API"
---

Dahl exposes an OpenAI-compatible API at `https://inference.dahl.global/v1`. Bifrost uses `/chat/completions` and `/models`.

```json
{
  "providers": {
    "dahl": {
      "keys": [{ "name": "dahl", "value": "env.DAHL_API_KEY" }]
    }
  }
}
```

Requests use Bearer authentication. Chat completions, streaming, model listing, and Responses-to-Chat fallback are supported.
