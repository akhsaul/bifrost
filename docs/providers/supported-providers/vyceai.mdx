---
title: "VyceAI"
description: "Configure VyceAI through its OpenAI-compatible API"
---

VyceAI exposes an OpenAI-compatible API at `https://vyceai.com/v1`. Bifrost uses `/chat/completions` and `/models`.

```json
{
  "providers": {
    "vyceai": {
      "keys": [{ "name": "vyceai", "value": "env.VYCEAI_API_KEY" }]
    }
  }
}
```

Requests use Bearer authentication. Chat completions, streaming, model listing, and Responses-to-Chat fallback are supported.
